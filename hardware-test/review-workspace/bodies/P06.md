# [Intel Mac P06] Retire the legacy SPI package alongside T1Bridge

Carry omacom/omarchy#9880’s legacy SPI cleanup with explicit retirement prerequisites. On T1 models the migration now requires the T1Bridge packages; for every retained kernel it checks an actual in-tree applespi module. Complete the accepted P12 manual provider transition before removal: these checks do not prove live handoff or firmware setup.

The full source suite passed 273 files with two disclosed skips, but repeated NetworkManager Polkit failures during that suite temporarily locked its test account. The following password/desktop/recovery checks failed there and passed separately in a clean overlay of the same ISO; the original aggregate remains failed.
