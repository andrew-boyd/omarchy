# [Intel Mac P14] Consolidate suspend diagnostics

Carry omacom/omarchy#11904’s standalone suspend diagnostics command with software recovery repairs. Failed restores remain retryable, privileged state is private and locked, interrupted diagnosis stops after restoration, failed sleep tests return failure, and existing rules are preserved. It adds no automatic boot, installer or sleep hook.

**Draft consolidation for source review and hardware-owner follow-up.** Known defects remain; no hardware or merge-readiness certification is claimed.
