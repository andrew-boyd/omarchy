# [Intel Mac P05] Handle ghost internal displays

Combine the existing ghost-display recovery commands and watcher with backend display filtering. A software follow-up keeps identityless, modeless external connectors available in the panel; internal ghost filtering and the existing enabled-count guard remain.

**Draft consolidation for source review and hardware-owner follow-up.** Known defects remain; no hardware or merge-readiness certification is claimed.
