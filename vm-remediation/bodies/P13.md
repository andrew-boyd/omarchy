# [Intel Mac P13] Consolidate the Intel Mac kernel migration policy

Retain the existing Apple-vendor kernel-policy exemption. A software follow-up keeps migration pending when DMI vendor information is missing or unreadable and accepts case variants of the existing Apple prefix. It adds no hardware-specific kernel choice or automatic rollback.

**Draft consolidation for source review and hardware-owner follow-up.** Known defects remain; no hardware or merge-readiness certification is claimed. Part of the [14-feature Intel Mac series](https://github.com/andrew-boyd/omarchy/blob/intel-mac/review-index/INTEL-MAC-ROLLUPS.md) with three package companions.

**Contribute:** open follow-up PRs in `andrew-boyd/omarchy` with base **`intel-mac/p13-kernel-policy`**. Use `[Intel Mac P13]` in the title and a contributor branch such as `intel-mac/p13/describe-change`. Link this feature in the series index. Merging a follow-up into this branch updates its roll-up.
