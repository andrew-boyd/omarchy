# [Intel Mac P07] Preserve the MacBook8,1 SPI PIO workaround

Consolidate the existing MacBook8,1 PIO/s2idle contribution. Follow-up software repairs preserve custom configuration, append SPI modules to the base list, require the complete shipped boot-parameter pair, and keep failed rebuilds retryable. The hardware parameters are unchanged.
