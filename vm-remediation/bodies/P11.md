# [Intel Mac P11] Consolidate model-specific Cirrus audio support

Consolidate the separate Cirrus audio tracks while keeping their model and package boundaries. Software follow-ups anchor the CS8409 model gate, avoid an unrelated stock-header request, preserve custom service/user configuration and back up saved routes. Driver and mixer tuning are unchanged.

**Draft consolidation for source review and hardware-owner follow-up.** Known defects remain; no hardware or merge-readiness certification is claimed. Part of the [14-feature Intel Mac series](https://github.com/andrew-boyd/omarchy/blob/intel-mac/review-index/INTEL-MAC-ROLLUPS.md) with three package companions.

**Contribute:** open follow-up PRs in `andrew-boyd/omarchy` with base **`intel-mac/p11-cirrus-audio`**. Use `[Intel Mac P11]` in the title and a contributor branch such as `intel-mac/p11/describe-change`. Link this feature in the series index. Merging a follow-up into this branch updates its roll-up.
