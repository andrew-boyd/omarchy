# Per-feature VM coverage

These are results for the combined pinned ISO, not physical hardware certification. Build 5 carries the broad checks; Build 6 repeats installation/acceptance and verifies the only changed package. See [handoff](HANDOFF.md), [final receipt](receipts/final-validation.json), [source reconstruction](integration/sources.json), [logs](logs) and [screenshots](screenshots).
